# MySQL Practice

My SQL queries and database practice assignments using MySQL.

## Topics

- Creating tables and inserting data
- SELECT queries
- Filtering with WHERE
- Sorting with ORDER BY
- Joining tables with JOIN and LEFT JOIN
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- Grouping results with GROUP BY

## Practice Database

Student management database with students, courses, instructors, enrollments, grades, and projects.

## Running Queries

Open a .sql file in MySQL Workbench, select the student_management database, and execute the query.
